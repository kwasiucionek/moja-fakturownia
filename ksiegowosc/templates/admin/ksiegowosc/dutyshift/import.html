Import grafiku dyżurów

Wklej grafik — jedna linia na dyżur, wartości oddzielone średnikiem lub tabulatorem:

DATA;OD;DO;RODZAJ;OPK;UWAGI
  • DATA — format DD.MM.RRRR (np. 04.07.2026)
  • OD / DO — godzina, np. 20:00 lub 8:00. Dyżur przechodzący przez północ jest liczony poprawnie (do < od = następny dzień).
  • RODZAJ — "samodzielny" (albo "sam"/"s") lub "towarzyszący" (domyślnie, jeśli puste)
  • OPK i UWAGI — opcjonalne, można pominąć

Przykład (dokładnie to, co dostajesz w podsumowaniu tabeli dyżurów):

04.07.2026;20:00;8:00;samodzielny
07.07.2026;18:00;8:00;towarzyszacy;500-00-16
17.07.2026;18:00;8:00;towarzyszacy
